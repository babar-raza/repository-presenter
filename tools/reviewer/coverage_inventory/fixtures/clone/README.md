# Widget Kit

![badge](https://img.shields.io/x)

## Installation

Run `pip install widget-kit` to get the library.

## Quick start

Create a widget and render it with the render pipeline and the layout engine.

## Command line

Use `widget-cli convert input.txt output.pdf` to convert a file from the terminal.
