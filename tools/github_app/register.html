Register: Repository Presenter GitHub App

This is the one manual step in OWNER-04. Clicking the button below submits the manifest below to GitHub's own app-creation form — everything after that (the credential exchange, secret storage) is scripted.



  

    
    
  


  
    
    
  1. Click the button above. GitHub shows a confirmation page for the app described in the
        manifest (name, permissions, no webhook). Confirm/create it.
    2. 
    
  2. GitHub redirects your browser to
        https://github.com/babar-raza/repository-presenter?code=...&state=....
        That page won't do anything special — just copy the full URL from your address bar
        right after the redirect (the code is single-use and expires in about an hour).
    3. 
    
  3. Paste that full URL back to the agent/session that gave you this file. It will run
        tools/github_app/register_exchange.py to exchange the code for the app's
        credentials and store them as encrypted GitHub Actions secrets on
        babar-raza/repository-presenter — nothing is written to disk or printed in full.
    4. 
    
  4. Separately, install the app: open
        https://github.com/settings/apps/<app-slug>/installations (the slug is
        shown right after creation) and approve installation on each aspose-*-foss
        org you administer. This is a second manual, per-org click GitHub requires — there is no
        API path around it for a first installation.
