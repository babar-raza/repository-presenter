# G. Canonical durable **production** state machine

This is a target state design; map it onto existing `docs/STATE_MACHINE.md` transaction records and code rather than introducing an overlapping store.

| State | Entry/exit predicate and owner | Failure and resume |
|---|---|---|
| `DISCOVERED` | Registry admission/visibility verified; scheduler records due source revision | `BLOCKED_EXTERNAL` when private/moved; independent repo can continue |
| `SNAPSHOTTED` | Exact HEAD/readme/package provenance persisted | Retry metadata read with bounded backoff; recheck HEAD at end |
