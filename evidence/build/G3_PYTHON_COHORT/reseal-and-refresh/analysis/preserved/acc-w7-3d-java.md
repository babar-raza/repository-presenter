1. Title: `mvn test` and `mvn clean package` fail on a clean checkout. Body: .gitignore ignores `testdata`; FormatDetectionTests (10 tests) throw `IOException: Test file not found: testdata/input/cube.obj | testdata/stl/stl_ascii.stl | testdata/gltf/simple_cube.gltf`; StlFormatTest.testCreateSimpleStlBinary fails on Windows (`FileSystemException ... being used by another process`, a stream is left open). Repro: `git clone --depth 1 https://github.com/aspose-3d-foss/Aspose.3D-FOSS-for-Java && cd Aspose.3D-FOSS-for-Java && mvn -B test` (JDK 21.0.12, Maven 3.9.9): Tests run 61, Errors 11. Fix: commit fixtures under src/test/resources or generate them in the tests; close the stream before delete. Severity medium. Proof: the command above.
2. Title: binary STL import returns an empty scene. Body: FileFormat.java StlReader.load reads 5 bytes to test for 'solid', then readBinaryStl skips 80 header bytes from the same stream, so every field is read 5 bytes late; exceptions are swallowed (`catch (Exception e) { // Ignore }`) and the mesh is empty. Also a binary file whose header starts with 'solid' is parsed as ASCII. Repro: write an 80-byte-header binary STL with 2 triangles, `Scene.fromFile(path)`, count polygons: 0 on 26.5.0 and on main. Fix: PushbackInputStream or mark/reset, and decide ASCII by the 84 + 50n size rule. Severity high.
3. Title: STL export silently skips primitives; `Scene.save(path, new StlSaveOptions())` throws on main. Body: StlWriter exports only `instanceof Mesh` entities, so the README example `new Box(2,2,2)` -> `scene.save("box.stl")` writes an empty STL (84 bytes binary / 35 bytes ASCII); and on main `StlSaveOptions()` leaves fileFormat null so Scene.save(String, SaveOptions) -> save(OutputStream, FileFormat, SaveOptions) throws `IOException: File format not specified in SaveOptions` (Scene.java L402); on 26.5.0 `save(path, FileFormat.STLASCII)` writes binary. Repro: Probe2 (scene.save with each form, hexdump). Fix: convert IMeshConvertible entities with toMesh() in the writers; give StlSaveOptions() a default format. Severity medium.
4. Title: `Scene.fromStream(InputStream)` and `Scene.open(Stream)` without a format throw NullPointerException. Body: `options` is null at `options.getFileFormat()` (Scene.java L212-229). Repro: `Scene.fromStream(new FileInputStream("cube.stl"))`. Fix: detect with IOService.detectFormat. Severity medium.
5. Title: recognised formats are silent no-ops.
